# Animation

Enemy animation, driven by **Animancer** (+ Animancer.FSM).

## Key files

- `EnemyAnimation.cs` — plays enemy animation states (idle/move/attack/death) in response to AI/combat.

## Depends on / Used by

- Animancer plugin; used by **Control**/**EnemySpawnManagement** enemy prefabs.

## Language

> Stub.

**Animation State**: An Animancer clip/state (idle, move, attack, death) selected by control/combat logic.
